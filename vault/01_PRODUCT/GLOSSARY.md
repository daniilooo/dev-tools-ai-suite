# Glossário (produto)

| Termo | Significado |
|---|---|
| Suíte | A Dev Tools AI Suite instalada localmente |
| Dashboard | Interface web Angular servida em `127.0.0.1` |
| Provedor | Ferramenta de IA externa integrada (Claude Code, Codex, Ollama) |
| Adapter | Implementação de uma porta para um provedor/mecanismo específico |
| Core | Módulos sempre presentes (config, segurança, projetos, terminal) |
| Módulo opcional | Recurso cuja ausência não impede o Core (RAG, Graphify, Ollama) |
| Doctor | Comando `devtools doctor` de diagnóstico |
| Diretório de dados | `~/.dev-tools-ai-suite/` |
| SUG01/02/03 | Códigos das funcionalidades Agent Monitor, Quota Monitor, Integrated Terminal |
| Local-first | Funciona sem servidores próprios ou internet para o essencial |

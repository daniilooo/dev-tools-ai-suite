# REPORTER

Resumo · status · alterações · testes · riscos · bloqueios · próximos passos.

|---|---|

| PO | escopo, critérios de aceite, progresso da fase |
| Gestor | percentual por fase, bloqueios, previsão |
| Daily | ontem / hoje / bloqueios (≤ 5 linhas) |
